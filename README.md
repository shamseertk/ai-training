# AI Training Notebooks

This repository contains notebooks covering data exploration, APIs, model validation, OpenAI chat completions, and document embeddings.

## Notebooks

- [ai-chapterone.ipynb](./ai-chapterone.ipynb) — explores a customer-review dataset and its structure.
- [ai-fastapi.ipynb](./ai-fastapi.ipynb) — builds and tests a FastAPI sentiment-analysis service.
- [ai-marketing-openai-langchain.ipynb](./ai-marketing-openai-langchain.ipynb) — calls OpenAI chat completions for marketing-related prompts and loads the API key from the environment.
- [ai-pydantic.ipynb](./ai-pydantic.ipynb) — validates review and sentiment request/response data with Pydantic models.
- [ai-text-generation-pipeline.ipynb](./ai-text-generation-pipeline.ipynb) — loads and chunks text/PDF documents, then creates embeddings with Hugging Face or OpenAI.
